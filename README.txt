# Rasho Enterprises Website

A modern, responsive company-profile website inspired by the structure of the reference Jeet Enterprises website, but designed from scratch for Rasho Enterprises.

## Files
- index.html — complete website
- styles.css — responsive styling
- script.js — menu, gallery lightbox and active navigation
- assets/ — place your logo and project images here

## Before publishing
1. Replace the demo Unsplash images in `index.html` with Rasho Enterprises project images.
2. Replace the email if needed.
3. Add your phone/WhatsApp number and business address.
4. Upload all files to your hosting public_html folder.
5. Keep `index.html` as the homepage.

## Suggested domain
rashoenterprises.in or another available domain of your choice.
